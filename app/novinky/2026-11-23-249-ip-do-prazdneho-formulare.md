## Opravy

- #249 - Další IP adresa, subnet nebo API klíč jde přidat i do rozepsaného formuláře
  Tlačítka „Přidat další IP“, „Přidat další Subnet“ a „Přidat další API klíč“ v úpravě člena a AP dřív nepřidala řádek, dokud nebyla vyplněná všechna povinná pole. Teď řádek přidají hned a rozepsané hodnoty nechají být; ukládá se až tlačítkem Uložit.
